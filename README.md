# 🏦 Plataforma Bancaria

## 📌 Descripción del proyecto

Plataforma Bancaria es un sistema de información básico desarrollado para simular procesos principales de una entidad bancaria.

El sistema permite gestionar clientes y cuentas bancarias mediante una aplicación desarrollada en Python, aplicando Programación Orientada a Objetos (POO), almacenamiento en archivos JSON y control de versiones con Git utilizando la metodología Git Flow.

---

## 🚀 Funcionalidades del sistema

### 👥 Módulo de clientes

- Registrar clientes.
- Listar clientes.
- Buscar clientes por documento.
- Actualizar información de clientes.
- Eliminar clientes.

### 💳 Módulo de cuentas

- Crear cuentas bancarias.
- Consultar cuentas.
- Administrar información de cuentas.

### 💰 Operaciones bancarias

- Consignaciones.
- Retiros.
- Transferencias.

## 🌿 Control de versiones

El proyecto utiliza Git Flow:

- `main`: contiene versiones estables.
- `develop`: rama de integración.
- `feature/*`: ramas para desarrollar funcionalidades.

Ramas principales:

- feature/registro-clientes
- feature/creacion-cuentas
